# EchoSub 功能清单

> 用途：给 UI 原型设计用的功能说明。这里只写软件能做什么、有哪些数据和状态、有哪些技术限制，不规定任何界面布局、样式或交互形式。
> 视觉上唯一的要求：**液态玻璃（Liquid Glass）**。
> 依据：`echosub-mygo` 当前代码（Go + mygo v0.7.4，macOS 原生界面）。

## 1. 产品是什么

EchoSub 是一个 macOS 上的 YouTube 双语字幕学习工具。用户粘贴 YouTube 链接后，软件自动获取英文字幕，用大模型翻译成简体中文，然后一边播放视频一边按时间显示双语字幕。字幕还可以放到独立的悬浮窗口和桌面歌词窗口里，盖在其他 App 上面，方便边看边做别的事。

目标用户是用真实视频练英语听力的人，核心场景是逐句精听：反复听一句、一句一句往前走、对照中文理解。

## 2. 软件由哪几部分组成

| 部分 | 说明 |
|---|---|
| 主窗口 | 视频播放、字幕阅读、视频库管理、设置入口 |
| 悬浮字幕窗口 | 独立窗口，滚动显示字幕，可置顶 |
| 桌面歌词窗口 | 独立窗口，只显示当前一句，可锁定成鼠标穿透 |
| 菜单栏图标 | 主窗口不在前台时，控制播放和两个悬浮窗 |
| App 菜单 | macOS 顶部菜单，提供带快捷键的命令 |
| 设置 | 翻译服务、字幕来源、外观、悬浮窗选项、快捷键说明 |

## 3. 视频库

### 3.1 添加视频

- 输入框接受这些格式：
  - `youtube.com/watch?v=…`
  - `youtu.be/…`
  - `youtube.com/shorts/…`、`/embed/…`、`/v/…`、`/live/…`
  - 单独的 11 位视频 ID
- 输入时实时识别视频 ID。识别成功时给出提示；如果这个视频已经在列表里，也会提示。
- 回车或点"添加"提交。无法识别时报错："无法识别这个 YouTube 链接。"
- 有一个"从剪贴板粘贴"的操作。
- 添加已存在的视频时，直接切换到它。如果它之前被隐藏，会自动恢复。
- 新视频添加后自动开始获取字幕，获取成功后自动开始翻译。

### 3.2 每个视频的信息

| 字段 | 说明 |
|---|---|
| 标题、频道 | 获取字幕时一并抓取；抓到之前显示占位文字"YouTube 视频" |
| 缩略图 | 来自 YouTube，后台下载 |
| 时长 | 获取字幕后才有 |
| 观看进度 | 上次看到的位置，切换视频或每 10 秒自动保存，再打开时从这里继续 |
| 字幕状态 | 见下表 |

字幕状态：

| 状态 | 含义 |
|---|---|
| 待获取 | 还没开始 |
| 获取中 | 正在按顺序尝试三个字幕来源 |
| 翻译中 | 字幕已拿到，正在分批翻译；可以算出百分比 |
| 双语 | 已就绪（可能仍有少量句子没翻译，见 5.4） |
| 无字幕 | 视频本身没有可用字幕 |
| 失败 | 三个来源都失败，附带每个来源的错误信息 |

多个视频可以同时处于"翻译中"，切换视频不会中断其他视频的翻译。App 重启后，残留的"翻译中"会恢复成可以继续操作的状态。

### 3.3 管理操作

- 选择视频：切换播放，并从上次的位置继续。
- 从头播放。
- 在浏览器中打开 YouTube 原页面。
- 复制视频链接。
- 隐藏：只是从列表里收起，字幕和翻译都保留。
- 查看已隐藏的视频，可以逐个恢复。
- 删除（需要二次确认）：永久删除视频信息、原字幕和中文翻译，无法恢复。
- 清空列表（需要二次确认）：删除当前列表里的所有视频，已隐藏的不受影响。
- 按标题或频道筛选。
- 列表循环模式，三选一，循环切换：关 / 列表循环 / 单个视频循环。

## 4. 字幕获取

### 4.1 来源与顺序

按顺序尝试，前一个失败才用下一个：

1. **YouTube 直连**：内置，不需要配置。先读网页里内嵌的字幕轨；失败了换 YouTube Android 客户端接口再试。
2. **本机 yt-dlp**：自动检测是否安装（例如 `~/.local/bin/yt-dlp`）。没装时可以提示 `brew install yt-dlp`。
3. **Supadata**：在线服务，需要用户填 API Key（可选），只读取已有字幕，不会触发 AI 转写费用。

公开视频不需要登录 YouTube。

### 4.2 处理

- 优先选英文字幕轨，记录是人工字幕还是自动字幕，以及来自哪个来源。
- 把零碎的字幕片段合并成可读的句子，每句有开始时间、结束时间和英文原文。
- 顺便补全视频标题、频道和时长。

### 4.3 重新获取

- 可以手动重新获取当前视频的字幕（需要确认）。重新获取会替换掉当前的中文翻译。
- 失败或无字幕时可以重试，也可以直接去 YouTube 打开视频。

## 5. 翻译

### 5.1 服务配置

- 支持任意 OpenAI 兼容接口（`/chat/completions`）。需要配置三项：服务地址、模型名、API Key。
- 内置三个快速预设：
  - DeepSeek（默认）：`https://api.deepseek.com`，`deepseek-chat`
  - 通义千问：DashScope 兼容模式，`qwen3-max`
  - OpenAI：`gpt-5-mini`
- "测试连接"：用一句示例文字实际请求一次。成功显示模型名和耗时，失败显示错误信息。
- API Key 支持显示 / 隐藏。

### 5.2 翻译方式

- 每批 4 句，同时附上前后各约 4 句作为上下文，还会带上视频标题。
- 要求模型返回 JSON。用 Qwen3 系列模型时自动关闭"思考"。
- 某一批失败后等一会儿重试一次，仍失败就跳过这一批，继续翻后面的。
- 每翻完一批立即保存并刷新显示，用户能看到翻译一句句出现。

### 5.3 自动触发

以下时机会自动开始翻译：
- 字幕获取完成后；
- 选中一个还有未翻译句子的视频时；
- 第一次填上 API Key 并保存时，会翻译当前视频。

### 5.4 部分完成与补全

- 有批次被跳过时，翻译结束后状态仍是"双语"，但会有若干句缺中文，需要显示"待补全 N 句"。
- 提供"补全翻译（N 句）"操作，只翻缺失的句子。
- 用户手动修改过的译文（`zhUserOverride`，目前由 Swift 版产生）优先于模型译文，Go 版会保留它。

### 5.5 没有 API Key

不翻译，只显示英文原文，并提示用户去配置。

## 6. 播放

播放器是嵌在窗口里的 YouTube 官方播放器（iframe），视频本身保持 16:9。

| 功能 | 说明 |
|---|---|
| 播放 / 暂停 | |
| 后退 / 前进 5 秒 | |
| 进度拖动 | 显示当前时间和总时长 |
| 播放速度 | 0.5× / 0.75× / 1× / 1.25× / 1.5× 循环切换 |
| 上一句 | 当前句刚开始不到 1.5 秒时回到上一句，否则回到当前句开头 |
| 下一句 | 跳到下一句开头 |
| 重听本句 | 回到当前句开头并播放 |
| 单句循环 | 当前句播完自动回到句首，直到关闭。用上一句 / 下一句切换时，循环跟着移到新的句子；用户在播放器里大幅拖动进度时，循环改为新位置所在的句子 |
| 窗口内全屏 | 视频铺满整个 App 窗口（不是 macOS 系统全屏），Esc 退出 |
| 视频循环 | 见 3.3：关 / 列表循环 / 单个视频循环 |
| 在 YouTube 打开 | 用浏览器打开原视频 |
| 当前句位置 | 实时给出"第 n / N 句" |
| 播放器错误 | 显示 YouTube 播放器错误码，例如视频禁止嵌入 |

## 7. 字幕阅读（主窗口内）

- **显示模式**：原文 / 中文 / 双语。悬浮字幕和桌面歌词共用这个设置。某句还没有中文时，"中文"模式下显示英文原文。
- **当前句**：根据播放时间高亮。
- **自动跟随**：开启时，列表随播放自动滚动到当前句。用户手动滚开后，自动跟随暂停，需要提供"回到当前句"的操作。用户可以彻底关闭自动跟随。
- **点击某一句**：跳到这句并播放。
- **单句操作**：从这里播放、单句循环这一句、复制这一句（中英文）。
- **搜索**：按英文或中文过滤句子。
- **复制全部字幕**：复制全文双语文本。
- **每句显示**：开始时间、英文原文、中文译文。
- **字幕整体状态**：
  - 正在翻译 x / y 句，带百分比；
  - 已全部翻译；
  - 待补全 N 句；
  - 仅原文（没有 Key）；
  - 字幕来源（YouTube / yt-dlp / Supadata）、人工 / 自动字幕、总句数、所用模型。

## 8. 悬浮字幕窗口

独立的 macOS 窗口，可以浮在其他 App 上面。

- 开关：在主窗口、App 菜单（⇧⌘F）或菜单栏图标里都能打开和关闭。
- 可以移动、可以缩放（最小约 260 × 96），记住上次的位置和尺寸。
- **按窗口高度自动调整显示内容**：
  - 高度小于 160：只显示当前一句（长句最多 3 行）；
  - 高度 160–300：显示上一句、当前句、下一句，前后两句只占一行；
  - 高度大于 300：显示可滚动的字幕列表，当前句保持在靠上的位置。
- 窗口内可用的操作：
  - 上一句、播放 / 暂停、下一句；
  - 字号增减（12–36）；
  - 切换显示模式；
  - 开关自动跟随；
  - 开关置顶；
  - 关闭。
- 点击某句可以跳转播放。
- **底板**：可以开，也可以关；关闭后背景完全透明，只剩文字。底板透明度可调（0–100%）。
- **其他选项**：置顶；在所有桌面空间（Spaces）显示。
- **文字颜色**：英文、中文分别取色，和桌面歌词共用一套配色（见 11.3）。

## 9. 桌面歌词窗口

独立的 macOS 窗口，一次只显示当前一句，可以显示在全屏 App 上面和所有桌面空间里。

- 开关：主窗口、App 菜单（⇧⌘D）或菜单栏图标。
- 宽度可以调，最小 360；高度跟着文字换行自动变化。英文最多 4 行，中文最多 3 行。记住上次的位置。
- 英文、中文字号分别调整（12–48）。默认英文 27、中文 18。
- 对齐方式：居中 / 左对齐。
- 背景透明度 0–100%。完全透明时文字需要额外保证可读性。
- **句内进度**：显示当前这一句播到了哪里（可在设置里关闭）。
- 窗口内可用的操作：上一句、播放 / 暂停、下一句、字号、对齐、透明度、锁定、关闭。
- **锁定**：锁定后窗口不再接收鼠标，点击会穿透到下层 App，窗口上的控件也全部不可用。解锁途径：菜单栏图标、App 菜单（⇧⌘L）。
- 没有字幕时显示占位文字。

## 10. 菜单栏图标与 App 菜单

### 10.1 菜单栏图标（常驻）

点击后展开菜单，内容如下：

### 10.2 App 菜单（macOS 顶部菜单）

- **EchoSub**：关于、设置…（⌘,）、隐藏、隐藏其他、全部显示、退出。

- **播放**：播放 / 暂停、上一句、下一句、重听本句、单句循环、后退 5 秒、前进 5 秒、播放速度。
- **窗口**：
  - 显示 / 隐藏悬浮字幕（⇧⌘F）
  - 显示 / 隐藏桌面歌词（⇧⌘D）

## 13. 需要覆盖的状态

设计时需要考虑这些情况：

- 视频库为空（首次使用）
- 正在获取字幕（可以先播放视频）
- 字幕获取失败（附三个来源的失败原因，可重试）
- 视频没有字幕
- 正在翻译（有进度）
- 翻译完成但有待补全的句子
- 未配置 API Key（只有原文）
- 字幕为空
- 搜索没有结果；筛选没有结果
- 没有隐藏的视频
- 播放器不可用；播放器报错（例如视频禁止嵌入）
- 测试连接：进行中 / 成功 / 失败
- 删除、清空、重新获取字幕三个确认
- 悬浮字幕：三种显示密度；有底板 / 无底板；没有视频时
- 桌面歌词：普通、锁定、背景全透明、窄宽多行、没有字幕时
- 悬浮字幕、桌面歌词各自的开 / 关，以及歌词的锁定状态（多处入口需要显示一致）
- 浅色 / 深色系统外观（主窗口跟随系统；两个悬浮窗目前固定为深色）

## 14. 数据与存储

- 数据目录：`~/Library/Application Support/EchoSub/`，与 Swift 版共用。
  - `library.json`：视频列表、字幕、翻译、隐藏列表、观看进度；
  - `credentials.json`：翻译 API Key、Supadata Key，明文，权限 600；
  - `settings.json`：Go 版自己的偏好设置。
- 窗口位置和尺寸会被记住（主窗口、悬浮字幕、桌面歌词）。
- 不需要登录，没有账号体系，也没有云同步。

## 15. 技术限制（设计时需要知道）

- **平台**：macOS 13 及以上；界面由 mygo 原生绘制，不是网页。
- **液态玻璃怎么实现**：
  - 窗口内的玻璃效果由 mygo 的 glass 插件绘制，只能折射窗口自己画的内容；
  - 窗口级的 Liquid Glass（`VibrancyGlass` / `VibrancyGlassClear`）由系统绘制，能透出桌面和其他 App。完整效果需要 macOS 26；更早的系统会退化成普通毛玻璃。悬浮字幕窗口可以用这种窗口级玻璃。
- **视频画面不能被玻璃模糊**：YouTube 播放器是系统 WebView，玻璃和模糊效果看不到它的画面。覆盖在视频上的元素可以显示，但没法对视频做模糊折射。
- **视频比例**：视频固定 16:9，窗口比例和视频不一致时需要考虑留白区域怎么处理。
- **没有文字阴影**：mygo 的阴影是盒阴影，不能给文字加阴影；透明背景下文字的可读性需要用别的办法解决。
- **悬浮窗是真正的系统窗口**：悬浮字幕和桌面歌词各自是独立窗口，可以单独放在屏幕任何位置，盖在其他 App 上面。桌面歌词锁定后完全不接收鼠标事件。
- **菜单栏图标和 App 菜单**：使用 macOS 系统菜单，外观由系统决定。
